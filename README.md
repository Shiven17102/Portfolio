## Tech

Plain HTML, CSS and vanilla JavaScript — no build step, no dependencies. Mouse-based parallax and tilt effects are done with CSS transforms. Fonts are loaded from Google Fonts (Space Grotesk + Inter).

## Running locally

This is a single static file. To view it locally, just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploying

Deployed on [Vercel](https://vercel.com):

1. Push this repo to GitHub.
2. In Vercel, click **Add New → Project** and import this repo.
3. Leave the framework preset as **Other** — no build config needed.
4. Click **Deploy**.
